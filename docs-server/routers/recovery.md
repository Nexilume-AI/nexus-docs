# Router 来源自动恢复

Provider 健康表示运行环境或账号可用；Router 还要检查每个来源的地址和模型。因此 Provider healthy 并不代表所有 Router 来源都能成功调用。

受管运行环境重启后端口可能变化。显式启动及周期健康刷新会同步符合条件的 Provider 和来源地址，只有地址变化才更新，并在事务提交后排队检查来源。周期扫描为即时任务调度失败提供后续恢复机会。

单个来源检查失败不会中断其他来源；禁用的来源、已停止或删除的运行环境不会自动启用。上游已删除、待就绪或不健康的模型仍不可用，需等待目录刷新和健康检查确认恢复。

如果希望等待上游恢复某个模型，可保留原模型绑定。系统不会自动替换成其他模型，也不能恢复上游已撤下的服务或补充账号额度。应先比较 Provider 当前地址与 Router 各来源地址，查看错误详情和上游模型目录，同时确认后台 worker 与周期任务正常运行。

客户端取消或流响应不完整与已确认的账号/额度故障分别处理，避免误将整个账号标记不可用。
